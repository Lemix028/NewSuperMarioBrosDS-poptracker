# New Super Mario Bros. DS PopTracker

Map tracker for the [Archipelago implementation of New Super Mario Bros. DS](https://github.com/Lemix028/Archipelago-NewSuperMarioBrosDS)

## Installation

Download the latest release and place the ZIP file in PopTracker's `packs`
folder. Start PopTracker, select the NSMBDS pack and connect to your
Archipelago room through the AP connection window.

PopTracker 0.35.4 or newer is recommended.

## Features

- Tracks all levels, Star Coins, blocks, bosses and Toad Houses
- Supports progressive and individual gate permits
- Supports world keys, optional routes and level randomization
- Opens the matching world and level map while playing
- Can also be used as a manual tracker without an AP connection

Map images are based on the collection at [Mario Mayhem](https://www.mariomayhem.com/downloads/mario_game_maps/new_super_mario_bros_maps.php).
